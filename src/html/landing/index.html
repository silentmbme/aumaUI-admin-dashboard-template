What is AumaUI built with?+

AumaUI is an HTML admin template built with Bootstrap 5, SCSS and vanilla JavaScript. Its pages use a shared project structure and reusable interface patterns.

What is included in the project?+

The project includes business dashboards, application pages, form and UI examples, chart pages, authentication screens and documentation. Browse the live dashboard and toolkit sections for previews.

How do I find a specific page or component?+

Use the project HTML pages as examples. The documentation page explains the project structure and where to find the included templates and assets.

Can I customize themes and layouts?+

Yes. Adapt SCSS variables and component styles, then use the appearance controls to preview light or dark themes, RTL direction and available layouts. Pages are designed to respond across desktop, tablet and mobile sizes.

Where can I get setup and license information?+

Read the included documentation for setup guidance. License terms depend on the marketplace license you choose; check the current license details before purchasing.
