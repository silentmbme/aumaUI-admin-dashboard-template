Version 1.0.0

Initial release - HTML / Bootstrap 5

v1.0.0 Initial release First documented package version

The first AumaUI release brings together a responsive Bootstrap 5 admin interface, a broad library of workflow pages, and the source tools needed to customize and build the template.

What's included

  • Dashboards for key business teams

    Sales, ecommerce, CRM, finance, logistics, HR, projects, support, and AI dashboard examples, with matching workflow pages for common tasks.

  • Flexible navigation and appearance

    Vertical and horizontal navigation, sidebar layout options, a live appearance customizer, color palettes, and light or dark theme modes.

  • Reusable interface and application pages

    Bootstrap-based cards, forms, tables, calendars, authentication screens, chat and mail views, file management, invoices, and other admin workflows.

  • Interactive plugin examples

    Chart integrations including ApexCharts, Chart.js, and ECharts; data tables; maps; calendars; file uploads; editors; and other interface plugins.

  • Editable source and local build workflow

    HTML pages and shared template parts, SCSS, JavaScript, and assets under src/. Run npm install and npm run dev to compile the styles, assemble pages, copy dependencies, and preview the generated dist/ output.

  • Customer guidance

    Setup and customization documentation, project FAQs, support contact details, and release notes to help customers get oriented.

Front-end template

Sample records and interface actions demonstrate the UI. Authentication, database storage, API connections, uploads, and server-side validation must be connected to your own application before production use.

Before installing an update

Protect your custom work

  1. Back up your application.

    Keep your existing source, configuration, and lockfile before replacing files.

  2. Review the changed files.

    Compare shared template parts, theme variables, page scripts, and dependency changes against your customizations. Avoid replacing the entire source folder without reviewing it.

  3. Install and rebuild.

    Run npm install, then npm run dev. The workflow recreates dist, so keep all changes in src.

  4. Verify your application.

    Check navigation, forms, charts, tables, light and dark modes, mobile layouts, and external API connections before deployment.
